# 民謡レーダー（kaidou-minyou）

アプリ名は「民謡レーダー」。近づくと民謡の地がレーダーに映る位置ゲーム。
街道沿いの民謡を集めるデータプロジェクト。位置ゲームの要素を持つ：
スポット（民謡の地）に緯度経度・チェックイン半径・ポイントを持たせ、
街道ルートでスポットをつなぐ。

## データ

- `data/nara.json` ― 奈良民謡スポット8件＋ルート3本（柳生街道／山の辺の道／吉野路）
- `data/nara.md` ― 同内容の一覧表

座標の精度は `coord_accuracy` で区別する（geocoded＝取得済み／area＝地名レベルの概略・要検証）。

## 予定

- 和歌山の民謡データ（紀伊路・熊野古道）
- 位置ゲーム側の実装（チェックイン、ルート踏破）
