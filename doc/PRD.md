# 民謡レーダー PRD（製品要求文書）

作成：2026-11-25 ／ 上位文書：doc/MRD.md、doc/CONCEPT.md ／ 体験設計：spec/ux.yaml、spec/ui.yaml

## 1. 製品概要

位置情報をもとに、近くの民謡スポットをレーダーと音声で知らせるアプリ。地図のリストは見せない。スポットに近づくとレーダーが反応し、圏内に入ると激しく反応する。到着するとその地の歌が聴け、歌のテーマをモチーフにしたメダルがもらえる。県ごとにメダル7枚で県章ゴールドバッジ、47県で民謡マスター。

## 2. スコープ

### 初期スコープ（モデル県）
- 奈良県・和歌山県の2県、各7スポット（厳選は評価軸によるコンペで決定：doc/spot-competition.md）
- レーダー／接近／圏内／到着／メダル／バッジの一連の体験
- スポットDBは JSON 形式（data/*.json）を正とする

### スコープ外（初期）
- 汎用版（観光スポット全般の音声案内ナビ）― 別アプリとして将来検討
- ユーザー同士の対戦・交換・ランキング
- アプリ内での音源の保持（外部リンクで接続する）

## 3. プラットフォーム

- **Android APK を本体とする**（2026-11-25 検討）
  - 理由：常時起動が前提。バックグラウンドでの位置検知とジオフェンス反応は PWA では成立しない（画面を閉じると検知が止まる）
  - 見るだけの面（企画説明・コレクション閲覧）は Web でもよい
- 縦持ち・片手操作、ダークテーマのみ（spec/ui.yaml）

## 4. 機能要求

### 4.1 レーダー
- 常時、現在地を中心にレーダーが回転表示される
- 近くのスポットは点として、方位と距離（km）だけが表示される。それ以外の情報は出さない（ドラゴンレーダーのシンプルさ）
- スポットの点はタップ不可。到達することでのみ開く

### 4.2 接近・圏内
- スポットに近づくと、点が大きく明るくなる。接近時に短いヒント音声が一度だけ流れる
- チェックイン範囲（スポットごとの radius_m）に入ると、レーダーが激しく反応する（点滅の加速・音・振動）
- 圏内では土地の情報（地誌・歌・昔の生活）が読める

### 4.3 到着・歌
- 到着で、その地の歌が再生される（音源は外部連携：Spotify / YouTube / 自治体アーカイブ）
- 歌詞と、昔の生活への遡りメモ（苦労と楽しみの記録）を表示する

### 4.4 メダル・バッジ
- 到着でメダルを1枚獲得。メダルの絵柄は歌のテーマ（暮らしの場面）をモチーフとし、歌ごとに異なる
- メダルの裏面：歌の一節と一言メモ
- 同じ県のメダル7枚で、その県のバッジ（県章を加工したゴールドバッジ）に変わる
- バッジ47個で民謡マスター。踏破記録（全329スポット）が一望できる

### 4.5 コレクション
- 47の県章バッジが並ぶ棚として表示。未獲得は県章の輪郭だけ
- 県を開くとメダル7枚（空きは輪郭だけ）が並ぶ

### 4.6 外部連携
- 祭り・イベントの日程データと連動し、開催が近いスポットの反応を強める
- チェックイン記録はスポットデータの検証（座標・現況）に使える形で残す

## 5. データ要求

スポット1件の項目（data/*.json、正は JSON）：

| 項目 | 内容 |
|---|---|
| id / song / reading | 歌の識別名と読み |
| lat / lng / coord_accuracy | 座標と精度（geocoded / area）。area は要検証として明示 |
| place / municipality | 土地の名前 |
| radius_m / points | チェックイン半径とポイント |
| category / kaidou | 分類（民謡・踊り・祭り）と街道ルート |
| theme | メダルのモチーフになる歌のテーマ（暮らしの場面） |
| memory | その土地のメモリー（昔の生活への遡り） |
| hint / voice_arrive | 接近ヒントと到着時の一言 |
| links | 外部連携（祭り・観光・音源・自治体アーカイブ） |

スポット選定は評価軸6つでコンペ採点する：代表性／徒歩ロジー／現地性／検証可能性／分布バランス／外部連携。

## 6. 非機能要求

- **常時起動**：バックグラウンドで位置を検知し、圏内入域に反応できること。電池消費は県単位データの事前保持と検知間隔の調整で抑える
- **オフライン**：スポットデータは県単位で事前に持てる。山間部の圏外でもレーダーは動く
- **歩行中利用**：画面を見なくても全フローが完走できる（音声が主経路）。強いフラッシュは使わない
- **出典と権利**：歌・歌詞・県章などの出典と権利への配慮をデータ項目として保持する

## 7. 未決事項

- 県章を加工する許諾とデザインルール（県ごとに確認が必要）
- メダルの絵柄の描き起こし方法（手描き／生成の線引き）
- 汎用版（音声案内ナビ）との画面・基盤の共有範囲
- APK の配布方法（ストア／直接配布）
