# 県をまたいだ歌の相互の影響 ― 分析メモ

対象：5県36スポット（和歌山7／奈良8／大阪7／徳島7／三重7）。根拠は各 data/*.json の note と出典に基づく。

## 1. 音頭の系譜は県境を往復する（大阪⇔滋賀）
- 交野節（大阪・交野）が元節となり、江州音頭（滋賀・八日市発祥）の全盛期を経て、河内音頭（大阪・八尾）として戻ってきて独自に発展した（osaka.json 河内音頭 note）。
- 一方向の伝播ではなく「出て、育って、戻る」往復型。大阪盆踊歌・堀江盆踊唄や住吉踊りも同じ大阪の盆踊り文化圏の中で互いに影響し合っているとみられる。

## 2. お蔭踊は「参りの道」そのものが拡散経路（三重⇔奈良）
- お蔭踊りは伊勢（三重）と柳生（奈良）の両方に収録されている。同名の踊りが県をまたいで存在する数少ない例。
- 伊勢側の note にある通り、お蔭参りのブームは「参りの沿道各地に広がった現象」。歌と踊りは目的地だけでなく、道そのものに沿って広がった。参宮街道（桑名→亀山→伊勢）と奈良側の街道が、拡散のインフラだった。

## 3. 木遣り歌のネットワーク（三重⇔全国）
- お木曳木遣（伊勢）の note は、Wikipedia「松前木遣」に伊勢のお木曳木遣の歌詞・伝承と「桑名の殿様」の由来が載ることを示す。木遣りは材木を運ぶ労働の歌で、港と建築現場を結ぶネットワークに乗って全国へ広がった歌の型。
- 桑名の殿様（桑名宿）もこの系譜に接続する。三重の2スポットは「伊勢参り」だけでなく「材木の労働歌」という別の軸でもつながっている。

## 4. 紀伊半島の筏・林業文化圏（奈良⇔和歌山⇔三重）
- 吉野筏流し歌（奈良・吉野川）、熊野川筏節（和歌山・熊野川町）、尾鷲節（尾鷲市）は、紀伊半島の木材輸送ネットワークの歌。尾鷲節は熊野古道ルートと県境で接続する（mie.json／region-map）。
- 吉野木挽唄（奈良）を含め、山で伐り、川で流し、海の港から出すという一連の労働の流れが、県境を越えた一つの文化圏を作っている。

## 5. 吉野川は一つの川が二県を貫く（奈良⇔徳島）
- 奈良の吉野川は、そのまま徳島の吉野川である。上流（奈良）に筏流し歌と木挽唄、下流（徳島）に麦打唄（吉野川流域）と祖谷の粉ひき唄・祖谷甚句が分布する。
- 同じ水系の労働歌が、流域の生業の違い（林業→農業）に応じて姿を変えた例として読める。県別データでは見えないが、水系で見ると一本の線になる。

## 6. 歌は港と船に乗って県を出る（和歌山→全国／海のネットワーク）
- 串本節（和歌山）は、Spotify「和歌山民謡 総覧」11曲の大半が異唱で占めるほど全国の歌手に歌われた（wakayama.json note）。地方の港町の歌が、レコードと船のネットワークで全国区になった例。
- みかん摘み唄の歌詞「あれは紀の国みかん船」が示すように、産物と歌は同じ船で運ばれた。淀川三十石船唄（大阪）、鳴門大漁節・鳴門馬子唄ばやし（徳島）も、海と川の輸送が歌の拡散路だったことを裏づける。

## まとめ ― アプリへの含意
1. 県バッジとは別に、「水系」「街道」「系譜」の横断リンクをスポット詳細に持たせると、県をまたぐ発見が生まれる（例：吉野筏流し歌 ⇔ 徳島麦打唄）。
2. ルートは県単位で閉じず、熊野古道・参宮街道・吉野川水系のように県境を越える線として描くのが正しい（region-map では尾鷲―熊野の接続として実装済み）。
3. UDC本応募での主張材料になる：「47県×7スポット」は行政区分のDBだが、その下に街道・水系・系譜のネットワークが流れている、という二層構造がこのDBの独自性。
