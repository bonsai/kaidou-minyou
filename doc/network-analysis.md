# 民謡ネットワークの類推 ― 5県36スポット

データ（data/*.json）から、スポット間の「つながり」を5つの規則で類推し、ネットワークとして構築した。
成果物：`data/network.json`（ノード36・エッジ45）、`doc/network.svg`／`doc/network.png`、公開ページ network.html。

## 類推の規則（エッジの種類）
| 種類 | 規則 | 本数 |
|---|---|---|
| 街道 | 同じ kaidou（街道）を持つスポットを沿道順に接続。熊野古道は和歌山・三重を同一コリドーとして接続 | 24 |
| 地理近接 | 直線距離12km未満のペア | 18 |
| 主題 | 筏・船・御田植など、暮らしの場面（テーマ）の共有 ※根拠は各 note | 7 |
| 水系 | 同じ川の流域（吉野川、熊野川・古座川、祖谷川） | 4 |
| 系譜 | note に根拠のある系譜関係（元節・源流・同名の流行踊り） | 4 |

※複数種類に当てはまるペアは1本のエッジに統合し、種類を複数保持する（合計はエッジ45本に対して種類延べ57）。

## エビデンスとコンフィデンス（2026-11-26 追記、schema 2）
各エッジは `links` として、カテゴリーごとの根拠（エビデンス）と信頼度（コンフィデンス 0–1）を保持する。エッジの代表カテゴリーと信頼度は、その中で最も信頼度の高いリンクのもの。
- エビデンスの例：系譜は note の引用（例：河内音頭の note「元節は交野節とされる」→ 交野節—河内音頭、信頼度0.9）。街道は kaidou フィールドの一致。地理近接は座標間の実測距離を明記。
- 信頼度の分布：**高（0.8以上）28本／中（0.6–0.79）7本／低（0.6未満）10本**。低はすべて地理近接（近さだけでは文化的なつながりの根拠として弱い、という正直な評価）。
- 代表カテゴリーの内訳：街道24／地理近接7／主題7／水系4／系譜3。

## 結果
- **県をまたぐエッジは13本**（全体の約29%）。県のまとまりは強いが、決して閉じていない。
- **連結成分は2つ**：35スポットの巨大成分＋孤立1件。
- **ハブ（次数の高いスポット）**：
  - お木曳木遣（三重・次数5）― 系譜の起点。伊勢音頭・桑名の殿様・吉野木挽唄へ伸びる
  - 御田植歌（奈良・次数5）― 神事芸能のハブ。住吉踊り（大阪）・那智の田楽（和歌山）と主題でつながる
  - 吉野筏流し歌（奈良・次数4）― 水系の橋。吉野川を下って徳島麦打唄・阿波踊りに接続し、熊野川筏節（和歌山）とも主題でつながる「県境の橋渡し役」
  - 熊野川筏節（和歌山・次数4）、住吉踊り（大阪・4）、阿波踊り（徳島・4）、徳島麦打唄（4）
- **県境の橋（ブリッジ）**：
  - 尾鷲節（三重）が熊野古道で和歌山側（勝浦節・熊野川筏節）への玄関
  - 茶摘み唄（奈良・伊勢街道）が かんこ踊り（三重・参宮街道）への玄関 ― 伊勢への道は奈良からも伸びている
  - お蔭踊（奈良）⇔お蔭踊り（三重）は唯一の「系譜」による県境エッジ
- **孤立ノード**：三輪素麺掛け唄（奈良）。山の辺の道に他のスポットが無く、12km圏にも相手がいない。ルート側の補強候補（山の辺の道にもう1スポット足すと全体が閉じる）。
- **祖谷の2曲**（徳島）は当初は独立成分だったが、祖谷川が吉野川の支流であることに気づき水系エッジで本流に接続した。類推の規則を増やすとネットワークの形が変わる好例。

## 読み取れる構造
1. **街道が骨格**（24本）。ネットワークの背骨はほぼ街道でできている ― 「徒歩ロジー」の裏付け。
2. **水系と系譜は県境専用の橋**。県をまたぐ13本のうち、水系4・系譜1（お蔭踊）・主題5はすべて「道ではないつながり」。地理が遠くても歌はつながる部分はここ。
3. **主題のエッジは海に多い**（船・港：三十石船唄・鳴門大漁節・串本節・みかん船）。海は街道の代わりに主題で結ぶ。
4. **ハブは「労働と神事」の歌**。観光名所の歌ではなく、木を曳く歌と田植の歌が中心に来る ― CONCEPT の「歌は失われた生活の記録」と一致する。

## アプリへの含意
- スポット詳細に「つながり」を表示するなら、この network.json がそのまま使える（types と basis＝根拠つき）。
- 県バッジとは別に「橋を渡る」体験（県境エッジを踏む）を実績にすると、徒歩ロジーの物語になる。
- 三輪素麺掛け唄の孤立は、奈良7スポット確定（コンペ）のときに山の辺の道の補強として扱える。
